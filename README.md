# Anatomy Study App — Starter Kit

- `assets/content/sample_deck_upper_limb.csv` — example items
- `assets/configs/scheduler_tuning.yaml` — Anki-style Learn scheduler
- `economy_config.json` — XP/coin rewards + shop tiers
- `wireframe_checklist.md` — screens to design
- `roadmap_8_weeks.md` — build plan
